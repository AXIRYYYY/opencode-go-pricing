各贴一次即可，以后打开自动拉取 · 只存 localStorage，不上传任何地方

Go Key 位置：本机 ~/.local/share/opencode/auth.json 中 "opencode-go" 项的 key（或 Windows 下 %USERPROFILE%\.local\share\opencode\auth.json，以实际安装位置为准）。
Go / DeepSeek 两个主卡片都支持浏览器直连：填好 Key 后直接拉取，不需要启动本地代理。如果直连失败，先检查网络、VPN 或浏览器插件是否拦截了跨域请求。
本地代理是可选项，只在两种情况下需要：①「分模型明细」要调 Console 的导出接口（该接口只允许 opencode.ai 自己的域名跨域）；② Zen 页面的实时可用性校验。需要时在仓库目录运行 python usage-proxy.py（Key 通过环境变量 OPENCODE_GO_KEY / OPENCODE_SERVICE_KEY / DEEPSEEK_API_KEY 或同目录 usage-proxy.keys.json 提供，详见 README），或 Windows 双击 start-proxy.bat，然后在上面的「本地代理（可选）」一栏填 http://127.0.0.1:8787。
「分模型明细」还需要另外的服务账号 Key（oc_sk 开头）：Console 里建好后填进 usage-proxy.keys.json 的 OPENCODE_SERVICE_KEY 字段并重启代理；该 Key 只放代理端，不经浏览器。
安全提示：DeepSeek 官方条款不建议把 Key 放前端页面；本页仅做个人自用，Key 只经浏览器直发官方域名（或你自己的本地代理）。建议使用可随时 revoke 的 Key，勿分享带 Key 的页面状态。

点上方「拉取明细」经本地代理拉取（需在 usage-proxy.keys.json 配 OPENCODE_SERVICE_KEY），或把 Console Logs 页导出的 JSON/CSV 文件拖进来。
  • Go 三档为订阅级限额：同一订阅下换哪个 Key 查都一样；多订阅才需要逐个查。
  • Go 接口返回的百分比取整到整数（如 5%，官方页面显示 5.9%），小数精度官方未开放；速度与外推采用多点回归计算以减小取整误差。
  • DeepSeek 余额为账号级：多个 Key 分通道只能看到同一个余额，分不清各通道消耗（接口本身不提供）。
  • DeepSeek 高峰时段为周一至周五 01:00–04:00 与 06:00–10:00 UTC（北京时间 09:00–12:00、14:00–18:00），其余时段（含周末）均为低峰价；顶部徽章与价格页同逻辑。
  • 分模型明细按官方 Usage API 的逐请求 cost 上卷；各窗口起点取 Go 用量接口的 resetsAt 切分，与配额窗口一致。Go 卡未加载时按固定假设滚动估算（5h 回溯/周一 UTC 起/30 天前），标记为「估算」。
