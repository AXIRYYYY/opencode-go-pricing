设置 · Key 与代理 Go Key ✗ DeepSeek Key ✗ 代理 ✗ （点击展开）

各贴一次即可，以后打开自动拉取 · 只存 localStorage，不上传任何地方

Go Key 位置：本机 ~/.local/share/opencode/auth.json 中 "opencode-go" 项的 key（或 Windows 下 %USERPROFILE%\.local\share\opencode\auth.json，以实际安装位置为准）。
Go 接口不允许浏览器跨域直连，因此 Go 卡必须走本地代理：在仓库目录运行 python usage-proxy.py（Key 通过环境变量 OPENCODE_GO_KEY / DEEPSEEK_API_KEY 或同目录 usage-proxy.keys.json 提供，详见 README），保持窗口开着即可。DeepSeek 卡可直连，代理仅作备用。
安全提示：DeepSeek 官方条款不建议把 Key 放前端页面；本页仅做个人自用，Key 只经浏览器直发官方域名（或你自己的本地代理）。建议使用可随时 revoke 的 Key，勿分享带 Key 的页面状态。

  • Go 三档为订阅级限额：同一订阅下换哪个 Key 查都一样；多订阅才需要逐个查。
  • Go 接口返回的百分比取整到整数（如 5%，官方页面显示 5.9%），小数精度官方未开放；速度与外推采用多点回归计算以减小取整误差。
  • DeepSeek 余额为账号级：多个 Key 分通道只能看到同一个余额，分不清各通道消耗（接口本身不提供）。
  • DeepSeek 高峰时段为周一至周五 01:00–04:00 与 06:00–10:00 UTC（北京时间 09:00–12:00、14:00–18:00），其余时段（含周末）均为低峰价；顶部徽章与价格页同逻辑。
